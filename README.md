# 🍹 What Should I Drink?

Мемная рулетка напитков. Нажимаешь кнопку — получаешь случайный напиток. От обычного эспрессо до «Крови девственницы» и «Dschinghis Khan». Есть статы (энергия, трезвость, вменяемость, настроение), ежедневный режим, миксы и поиск по названию.

## Что внутри

- **2600+ напитков** — базовые, редкие, легендарные и проклятые
- **Поиск по названию** — введи «Пушистик» или «Undertale» — найдёт
- **Микс** — смешай два напитка, получи третий (или умри)
- **Ежедневный режим** — один напиток на всех, сид от даты
- **Ачивки** — 20 штук, от «Первого глотка» до «Выжившего»
- **Ручной ввод** — если напитка нет в базе, игра создаст его из твоего слова
- **Чит-команды** — `/nodead`, `/god`, `/heal`, `/stats`, `/reset`, `/help`

## Откуда напитки

Коты, собаки, огурцы, снеговики, школа, медицина, программирование, музыка, Metal Family, Minecraft-блогеры, Genshin, Portal, GTA, Undertale, FNAF, DDLC, Roblox, Geometry Dash, Gacha Life, И.Н.М.Т., интернет-мемы и многое другое.

## Как играть

### Python-версия

```bash
pip install pygame-ce
python wsid_game.py
```

### Веб-версия

Открой `index.html` в браузере — или зайди по ссылке GitHub Pages.

## Управление

- **Кнопка «Что мне выпить?»** — случайный напиток
- **«Ежедневный»** — режим одного напитка на день
- **«Ввести»** — поиск по названию или своё слово
- **«Микс»** — смешать два напитка
- **Вкладки** — Игра / Ачивки / Мои
