# 🍹 What Should I Drink?

Мемная рулетка напитков на Python + pygame. Нажимаешь кнопку — получаешь случайный напиток. От обычного эспрессо до «Крови девственницы» и «Dschinghis Khan». Есть статы (энергия, трезвость, вменяемость, настроение), ежедневный режим, миксы и поиск по названию.

## Что внутри

- **2600+ напитков** — базовые, редкие, легендарные и проклятые
- **Поиск по названию** — введи «Пушистик» или «Undertale» — найдёт
- **Микс** — смешай два напитка, получи третий (или умри)
- **Ежедневный режим** — один напиток на всех, сид от даты
- **Ачивки** — 20 штук, от «Первого глотка» до «Выжившего»
- **Ручной ввод** — если напитка нет в базе, игра создаст его из твоего слова
- **Чит-команды** — `/nodead`, `/god`, `/heal`, `/stats`, `/reset`, `/help`

## Откуда напитки

Коты, собаки, огурцы, снеговики, школа, медицина, программирование, музыка, Metal Family, Minecraft-блогеры, Genshin, Portal, GTA, Undertale, FNAF, DDLC, Roblox, Geometry Dash, Gacha Life, И.Н.М.Т., интернет-мемы и многое другое.

## Как играть

### Установка

```bash
pip install pygame-ce
```

### Запуск

```bash
python wsid_game.py
```

### Сборка .exe (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed wsid_game.py
```

Готовый `.exe` появится в папке `dist/`.

## Управление

- **Кнопка «Что мне выпить?»** — случайный напиток
- **«Ежедневный»** — режим одного напитка на день
- **«Ввести»** — поиск по названию или своё слово
- **«Микс»** — смешать два напитка
- **Вкладки** — Игра / Ачивки / Мои

## Чит-команды

Вводятся в поле «Ввести», начинаются со слэша:

| Команда | Что делает |
|---|---|
| `/nodead` | Вкл/выкл бессмертие |
| `/god` | Статы 100 + бессмертие |
| `/heal` | Восстановить статы |
| `/stats` | Показать текущие статы |
| `/reset` | Сбросить игру |
| `/seed N` | Установить сид для ежедневного режима |
| `/help` | Список команд |

## Файлы

| Файл | Что это |
|---|---|
| `wsid_game.py` | основной код: логика, отрисовка, главный цикл |

| `data_crazy.py` | 2494 мемных напитка |
